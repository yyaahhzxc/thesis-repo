\section{Archival OCR and VLM Evaluation}
\label{sec:results_ocr_evaluation}

Ingesting historical municipal archives into an automated legal decision-support system requires converting scanned physical documents into structured digital text. In the Davao City collection, enactments from earlier legislative terms exist predominantly as scanned physical PDF records rather than searchable digital-born documents. These historical records exhibit real scanning noise, including paper skew, uneven ink contrast, staple shadows, and official municipal seal watermarks stamped over operative clauses. If degraded physical scans are transcribed with erroneous characters or broken layout geometry, downstream retrieval indices and inference models inherit corrupted tokens. This section establishes a multi-dimensional evaluation framework for legislative document transcription, presents a stratified archival reference sampling design, compares four candidate optical character recognition paradigms, and details the empirical justification for adopting a locally hosted vision-language model.


\subsection{Architectural Paradigms and Candidate Systems}
To determine the most viable document extraction method for historical municipal archives, the proponents evaluated four distinct architectural paradigms. Traditional optical character recognition relies on classical image binarization, connected component analysis, and heuristic line slicing, followed by character sequence prediction using a lightweight 1D CNN-LSTM architecture~\cite{smith2007overview}. As exemplified by Tesseract v5.x, traditional engines evaluate individual characters as isolated visual glyphs without semantic sentence context. While computationally efficient on central processing units, traditional engines degrade rapidly when encountering skewed lines or physical paper bleed-through.

Document-layout OCR frameworks decouple spatial document segmentation from line text recognition~\cite{paruchuri2024surya}. Modern implementations such as Surya v0.6+ employ visual object detection backbones to identify bounding polygons for text columns, tables, and headers. A separate recognition model then transcribes text lines, after which reading order is reconstructed through topological sorting heuristics. This modular decoupling provides robust layout preservation on multi-column pages, but requires multi-stage neural pipelines that demand substantial graphics memory during sustained batch processing.

Proprietary cloud vision platforms deploy large-scale multimodal transformers hosted on distributed enterprise server clusters~\cite{google2024documentai}. Commercial endpoints such as Google Cloud Document AI achieve high optical recognition accuracy across diverse scan qualities and complex table structures. However, commercial cloud services require active internet connectivity, incur ongoing per-page API fees, and necessitate external transmission of municipal documents. In an edge-deployed local government setting, recurring subscription costs and cloud data transfer contradict operational independence and statutory data sovereignty.

Local vision-language models unify visual patch encoding and autoregressive text generation within an end-to-end transformer architecture~\cite{bai2025qwen25vl}. Using two-dimensional rotary position embeddings (2D-RoPE) and dynamic patch allocation, visual features are projected directly into a causal language model decoder. Under 4-bit NormalFloat4 (NF4) quantization~\cite{dettmers2024qlora}, foundation models such as Qwen2.5-VL-3B-Instruct execute completely offline on consumer workstation hardware. The internal causal language decoder acts as an intrinsic linguistic prior, allowing the model to resolve visual ambiguities by drawing on internal syntactic and statutory representations.


\subsection{The Multi-Dimensional Evaluation Framework}
Evaluating document transcription on municipal legislation exposes vulnerabilities that general-domain OCR benchmarks fail to capture. As Lopresti demonstrated~\cite{lopresti2008optical}, optical character recognition errors trigger an error cascade across subsequent natural language processing layers. In statutory construction, a single mutated character or omitted numeral corrupts governing legal semantics. A comprehensive evaluation framework for legislative transcription must combine classical string edit distances with specialized legal entity accuracy metrics and dense semantic embedding fidelity.

The foundational character and word accuracy metrics are formulated via the Levenshtein edit distance $\mathcal{L}_{\text{Lev}}$~\cite{levenshtein1966binary}. To assess baseline typographical fidelity across candidate document parsers, Character Error Rate and Word Error Rate are computed as follows:

\noindent\textit{Character Error Rate (CER) and Word Error Rate (WER):}
\begin{equation}
    \text{CER} = \frac{\mathcal{L}_{\text{Lev}}(\mathbf{c}_{\text{ref}}, \mathbf{c}_{\text{hyp}})}{|\mathbf{c}_{\text{ref}}|} = \frac{S_c + D_c + I_c}{N_c}, \quad
    \text{WER} = \frac{\mathcal{L}_{\text{Lev}}(\mathbf{w}_{\text{ref}}, \mathbf{w}_{\text{hyp}})}{|\mathbf{w}_{\text{ref}}|} = \frac{S_w + D_w + I_w}{N_w}
    \label{eq:cer_wer}
    \eqcaption{Character Error Rate (CER) and Word Error Rate (WER)}
\end{equation}
\noindent Where $S$, $D$, and $I$ denote character or word substitutions, deletions, and insertions relative to the gold-standard reference sequence of length $N$.

Equation~\ref{eq:cer_wer} formulates Character Error Rate (CER) and Word Error Rate (WER) using normalized Levenshtein string edit distances. These foundational metrics are incorporated to establish an initial, length-invariant baseline of typographical fidelity when transcribing historical physical enactments. The equations quantify the sum of character or word substitutions ($S$), deletions ($D$), and insertions ($I$) relative to the total token count of the gold reference transcript ($N$). In legislative document ingestion, low global CER values can obscure catastrophic localized errors, as omitting a single numerical digit in a penalty clause alters the legal meaning entirely. Consequently, while CER and WER quantify coarse optical recognition noise, they treat all tokens symmetrically, necessitating complementary domain-specific accuracy metrics for statutory entities.

To evaluate overall document similarity on a bounded scale regardless of clause length, the proponents compute Normalized Edit Distance:

\noindent\textit{Normalized Edit Distance (NED):}
\begin{equation}
    \text{NED}(\mathbf{s}_{\text{ref}}, \mathbf{s}_{\text{hyp}}) = 1.0 - \frac{\mathcal{L}_{\text{Lev}}(\mathbf{s}_{\text{ref}}, \mathbf{s}_{\text{hyp}})}{\max(|\mathbf{s}_{\text{ref}}|, |\mathbf{s}_{\text{hyp}}|)}
    \label{eq:ned}
    \eqcaption{Normalized Edit Distance (NED)}
\end{equation}
\noindent Where $\mathbf{s}_{\text{ref}}$ and $\mathbf{s}_{\text{hyp}}$ denote the reference and hypothesis string sequences, bounded between 0.0 (maximum dissimilarity) and 1.0 (exact match) to provide a length-invariant evaluation baseline.

Equation~\ref{eq:ned} defines Normalized Edit Distance (NED) as an inverted, length-bounded metric of string similarity. This formulation is included to provide an intuitive, normalized score ranging from 0.0 to 1.0 that remains stable across varying document lengths and section sizes. The equation scales the raw Levenshtein distance against the maximum string length between reference and hypothesis texts, subtracting the resulting ratio from unity so that an exact transcription yields a score of 1.0. In benchmarking candidate OCR engines across multi-page municipal ordinances, NED prevents lengthy boilerplate provisions from disproportionately skewing aggregate error measurements. This metric serves as a standardized indicator of overall string alignment before evaluating structural entity retention.

Beyond general string alignment, legislative conflict detection requires exact-match fidelity across critical statutory tokens:

\noindent\textit{Domain-Specific Legislative Component Accuracy:}
\begin{equation}
    \text{Metric Accuracy} = \frac{1}{|K|} \sum_{k \in K} \mathbb{I}\left( \mathbf{v}_{\text{hyp}}^{(k)} \equiv \mathbf{v}_{\text{ref}}^{(k)} \right)
    \label{eq:legal_metric_acc}
    \eqcaption{Domain-Specific Legislative Component Accuracy}
\end{equation}
\noindent Where $K$ represents the set of extracted legal entity instances, and $\mathbb{I}(\cdot)$ is an exact-match indicator function comparing hypothesis values $\mathbf{v}_{\text{hyp}}^{(k)}$ against gold references $\mathbf{v}_{\text{ref}}^{(k)}$.

Equation~\ref{eq:legal_metric_acc} formulates Domain-Specific Legislative Component Accuracy across critical statutory entity classes. This targeted evaluation metric is integrated to ensure that high-stakes legal indicators—including statutory citations, enactment numbers, penalty figures, and effectivity dates—are transcribed with verbatim alphanumeric precision. The formulation computes the proportion of extracted entity instances where the hypothesis string matches the gold standard reference exactly according to the indicator function $\mathbb{I}(\cdot)$. In local ordinance digitization, a minor character corruption in a Republic Act citation breaks downstream BM25 inverted index lookups and misdirects dense vector retrieval. Enforcing exact-match component accuracy verifies whether candidate transcription engines preserve the governing legal tokens required for reliable Stage~1 candidate retrieval.

These domain metrics evaluate exact string equality across critical legislative components: Legal-Entity Accuracy (LEA) for local administrative offices and private contracting parties; Ordinance-Number Accuracy (ONA) for municipal enactment numbers and series suffixes; Date Accuracy (DA) for enactment, approval, and effectivity dates; Monetary-Value Accuracy (MVPA) for fines, fees, and penalty ceilings; Section-Heading Integrity (SHI) for operative structural catchlines; and Page Completeness (PC) for sequential page preservation. Furthermore, tabular schedule fidelity is evaluated using Tree-Edit-Distance-based Similarity (TEDS)~\cite{zhong2020image}, measuring row-column cell adjacency across multi-tier tax and zoning grids. Finally, Semantic Embedding Cosine Fidelity (SECF) measures dense vector retention by calculating the cosine similarity between dense embeddings of the reference and hypothesis texts.


\subsection{The Insufficiency of Ordinary Spellchecking}
Standard lexical spellcheckers and unconstrained dictionary autocorrection tools are fundamentally incapable of evaluating legal document transcription. In statutory conflict analysis, the cost of semantic errors is highly asymmetric. If an OCR engine transcribes ``Section'' as ``Secton'', the edit distance is one and an ordinary spellchecker repairs the typographical slip easily. Conversely, if an engine transcribes a penalty of ``\textpeso 5,000.00'' as ``\textpeso 50,000.00'', or mutates ``shall'' into ``may'', or alters ``Ordinance No. 0667-21'' to ``Ordinance No. 0661-21'', ordinary spellcheckers detect zero lexical errors because all generated tokens represent valid dictionary words. In municipal jurisprudence under the \textit{Magtajas v. Pryce Properties} doctrine and Section~458 of Republic Act No.~7160, mutating a \textpeso 5,000.00 penalty ceiling into \textpeso 50,000.00 converts a valid local ordinance into an unconstitutional, \textit{ultra vires} act.

Furthermore, Philippine legislative enactments contain high concentrations of specialized terminology that trigger massive false-positive rates in generic spellcheckers. Municipal ordinances routinely incorporate statutory Latin maxims (\textit{in pari materia}, \textit{mutatis mutandis}, \textit{ultra vires}, \textit{ejusdem generis}), official administrative acronyms (CTTMO, CENRO, CPDO, LISSP), and indigenous Visayan and Mindanaoan toponyms. Davao City alone encompasses 182 administrative barangays, including localities such as Buhangin, Bunawan, Calinan, Marilog, Paquibato, Talomo, and Toril. Standard spellchecking algorithms aggressively flag these authentic names as misspellings. When automated autocorrection is enabled, generic tools destructively alter specialized local nomenclature into common English words, permanently corrupting statutory text.

\subsection{Defensible Selection Rationale and Hardware Boundaries}
Selecting Qwen2.5-VL-3B-Instruct as the primary archival ingestion engine resolves the technical trade-offs between extraction accuracy, operational expense, and statutory data sovereignty. While traditional OCR provides rapid CPU throughput, its inability to maintain section header geometry and its susceptibility to numeral substitution directly undermine Stage~1 lexical retrieval and Section-Level Specificity. Although commercial cloud platforms deliver strong extraction accuracy, deploying commercial APIs across 1,664 multi-page ordinances entails recurring financial expenses. Furthermore, transmitting unpromulgated local government drafts and internal committee working texts to external commercial cloud servers introduces legal compliance hurdles under Republic Act No.~10173 (Data Privacy Act of 2012)~\cite{philgov2012ra10173}. An edge-deployable local system simulating Local Government Unit IT constraints must remain independent of external subscription paywalls.

Deploying Qwen2.5-VL-3B-Instruct in 4-bit NF4 precision delivers enterprise-grade transcription accuracy while running entirely offline. The model processes pages deterministically, respects local data sovereignty, and operates within the 8~GB VRAM boundary of the Neural Training Workstation. The primary operational trade-off of the vision-language approach is computational latency. On the NVIDIA RTX 5050 Laptop GPU, transcribing a single scanned page requires approximately 4.0 to 8.5 seconds, compared to less than one second for traditional OCR. However, because archival corpus digitization is an offline, one-time preprocessing task, this latency expenditure is technically acceptable. Bounding page generation at 1,000 new tokens and isolating document execution within fault-tolerant resume checkpoints ensures dependable batch processing across the complete municipal collection.


\subsection{Empirical Limitations and Archival Ceilings}
The empirical evaluation of archival transcription reveals three concrete technical limitations that establish the performance boundaries of the system. First, physical document degradation imposes an asymptotic ceiling on optical character recognition. On historical carbon copies from the 1950s and 1960s where physical ink bleed-through overlaps characters from opposing page sides, even human legal annotators disagree on obscured numerals, indicating that recognition ambiguity stems from physical artifact loss rather than algorithmic insufficiency.

Second, complex multi-tier tabular schedules in historical municipal tax ordinances feature non-standard visual grids and irregular cell mergers. While the vision-language model successfully captures the numerical tax rates and cell contents in Markdown format, cell alignment variations in irregular tables depress automated Tree Edit Distance (TEDS) metrics despite verbatim preservation of substantive monetary numbers. Third, high-capacity dense embedding models can exhibit metric saturation, where a corrupted digit in a penalty clause results in only a fractional cosine similarity drop, masking a severe statutory preemption conflict. Addressing these edge cases reinforces the core architectural principle that automated ingestion serves as an assistive decision-support tool rather than an autonomous substitute for human legislative review.


\section{Stage 1 Candidate Retrieval}
\label{sec:results_stage1_retrieval}

In a two-stage legal conflict detection pipeline, the primary objective of Stage~1 coarse retrieval is to rapidly filter an extensive statutory collection of 27,096 enactments (176,421 searchable provisions), capturing all potentially preemptive provisions within a compact top-$k$ candidate shortlist ($k \in \{5, 10, 20, 50\}$). In automated legal informatics, coarse retrieval performance is judged primarily on candidate recall ($\text{Recall@}k$) and Mean Reciprocal Rank ($\text{MRR}$), rather than classification accuracy~\cite{manning2008introduction}. Candidate recall ($\text{Recall@}k$) quantifies the proportion of queries where the governing statutory provision is successfully retrieved within the top $k$ candidates, while Mean Reciprocal Rank ($\text{MRR}$) measures the reciprocal position of the first relevant statute ($1/\text{rank}$), rewarding models that place governing laws near the very top of the candidate pool. If the governing statutory enactment is omitted from the top-$k$ shortlist during Stage~1, downstream inference models in Stage~2 cannot detect the conflict regardless of their analytical reasoning capacity. Simultaneously, the shortlist must remain sufficiently compact ($k \le 50$) to avoid diluting the cross-attention mechanism or exceeding local workstation memory ceilings during subsequent pair-wise inference.

\section{Stage 2 Conflict Detection}
\label{sec:results_stage2_training}

Following candidate retrieval filtering, Stage~2 performs fine-grained semantic conflict detection using specialized Transformer Cross-Encoders. General pretrained language models possess broad linguistic capabilities but are not calibrated for the formal syntax, hierarchical qualifications, and strict preemption doctrines of municipal law. As observed in recent COLIEE benchmarks, zero-shot models routinely suffer from affirmative bias—the systematic cognitive tendency of pretrained language models to presume pairs are harmonious or logically non-conflicting unless prompted by superficial lexical negation markers—defaulting toward neutral or entailment classifications when confronted with legal text~\cite{alshehri2026cross, tran2026enhancing}. Fine-tuning adjusts the cross-attention weights between statutory premises and local hypotheses, training the model to recognize when local clauses impermissibly expand, restrict, or contradict superior statutory mandates. 

It is important to emphasize that the evaluations reported in this section represent initial model exploration, screening, and hyperparameter optimization experiments conducted on the initial 350-pair ground truth benchmark (expert-curated and adviser-reviewed) to establish baseline inductive properties, optimize internal configurations, and calibrate decision thresholds prior to the final human evaluation deployed by the 15 Sangguniang Panlungsod legal researchers. This section details the initial screening evaluations across 28 scouted models, supervised fine-tuning sweeps, candidate ablations, and convergence dynamics of candidate models.

Analyzing natural language inference pre-alignment and baseline contrasts (Axis 2) isolates the scientific value of initializing neural weights from multi-task NLI pretraining (MNLI, FEVER, ANLI) versus cold masked language modeling, while establishing an empirical contrast against the canonical supervised baseline (\texttt{bert-base-uncased}). Standard \texttt{bert-base-uncased} establishes the foundational supervised baseline at Conflict $F_1 = 0.8519$ (Val Loss = 0.5124). Upgrading the encoder architecture to modern disentangled attention without NLI pretraining (\texttt{deberta-v3-base}) improves Conflict $F_1$ to 0.8750 (+2.31\% over base BERT). Initializing from warm multi-task NLI checkpoints (\texttt{DeBERTa-v3-base-NLI}) further lifts Conflict $F_1$ to 0.8947 (+4.28\% over base BERT and +1.97\% over cold DeBERTa), while the scaled \texttt{DeBERTa-v3-large-NLI} achieves 0.9000 (+4.81\% over base BERT). Furthermore, all fine-tuned models substantially outperform the unadapted zero-shot baseline ($F_1 = 0.4545$), confirming that task-specific adaptation provides substantial performance benefits for statutory preemption detection.

Evaluating legal-domain pretraining adaptation (Axis 3) indicates that administrative regulatory pretraining (PoL-BERT-Large, Conflict $F_1 = 0.8696$) out-performs judicial case-law pretraining (Legal-BERT, Conflict $F_1 = 0.8571$). Both domestic models outperform Indian statutory pretraining (InLegalBERT, Conflict $F_1 = 0.8333$), confirming that vocabulary adaptation to regulatory codifications is more effective for local municipal ordinances than litigation-centric case text.

\subsection{Loss Dynamics and Convergence}
In supervised machine learning, the loss function mathematically quantifies the penalty incurred when the model's predicted probability distribution diverges from the actual ground truth labels. For multi-class natural language inference, the training objective optimizes Multi-Class Cross-Entropy Loss:

\noindent\textit{Multi-Class Cross-Entropy Training Loss Function:}
\begin{equation}
    \mathcal{L}_{\text{CE}} = -\sum_{c \in \mathcal{C}} y_c \log \hat{P}(c)
    \label{eq:cross_entropy_loss}
    \eqcaption{Multi-Class Cross-Entropy Training Loss Function}
\end{equation}
\noindent Where $y_c \in \{0, 1\}$ denotes the binary ground truth indicator for class $c \in \mathcal{C}$, and $\hat{P}(c)$ represents the calibrated softmax probability output by the model.

Equation~\ref{eq:cross_entropy_loss} defines the Multi-Class Cross-Entropy loss objective utilized for supervised fine-tuning of candidate Cross-Encoder architectures. This loss function is incorporated to penalize divergence between predicted class probabilities and ground truth NLI relationships (Entailment, Neutral, Contradiction). The formulation computes the negative log-likelihood of the ground truth label $y_c$, scaling penalization asymptotically as predicted confidence $\hat{P}(c)$ strays from certainty. During optimization over the 245 training pairs, backpropagating gradients from this loss iteratively updates transformer cross-attention weights, aligning internal representations with formal legal preemption structures. Minimizing cross-entropy loss drives the model toward confident, well-separated class assignments necessary for calibrated thresholding.

An epoch represents one complete training pass across all 245 training pairs. Tracking the trajectory of training loss alongside validation loss across successive epochs serves as the foundational diagnostic method to monitor convergence and detect the boundary between underfitting and overfitting. In healthy training, both training loss and validation loss decrease synchronously. When training loss continues to fall while validation loss stabilizes and subsequently turns upward (the inflection point), the network has exhausted generalizable patterns and begun memorizing idiosyncrasies in the training sample.

The fine-tuning and convergence results show that the Top 5 performing architectures (\texttt{DeBERTa-v3-large-NLI}, \texttt{DeBERTa-v3-base-NLI}, \texttt{ModernBERT-large}, cold \texttt{deberta-v3-base}, and \texttt{PoL-BERT-Large}) alongside the canonical \texttt{bert-base-uncased} baseline achieve the lowest holdout validation losses and stable generalization at Epoch~3. Therefore, these six specific architectures are advanced as the candidate finalists for the subsequent out-of-sample benchmark evaluation and final system deployment roadmap. \subsection{Sensitivity Analysis and Regularization}
The potential for model overfitting represents a critical vulnerability when adapting high-capacity transformer architectures (such as 86-million to 435-million parameter models) to a specialized, compact training set ($N_{\text{train}} = 245$). Left unregularized, a neural network readily memorizes idiosyncratic phrasing artifacts rather than learning broader statutory conflict principles, producing near-zero training error while failing on unseen municipal measures. The empirical training logs confirm that the tripartite regularization strategy—combining decoupled AdamW weight decay ($\lambda = 0.01$)~\cite{loshchilov2019decoupled}, attention and hidden dropout ($p = 0.10$)~\cite{srivastava2014dropout}, and early stopping validation checkpoints~\cite{prechelt1998early}—effectively curbed parameter over-specialization. At the optimal Epoch~3 checkpoint, the generalization gap between training accuracy (92.4\%) and holdout validation accuracy (84.6\%) remained tightly bounded at 7.8\%, indicating that the cross-encoders learned generalizable statutory preemption patterns rather than superficial keyword heuristics.

Candidate encoders also exhibited sharp sensitivity to the initial learning rate during hyperparameter grid exploration. At a conservative rate of $\eta = 1\times 10^{-5}$, models displayed noticeable underfitting, as the optimization trajectory progressed too slowly across the compact dataset and left validation loss elevated ($\ge 0.589$). Increasing the learning rate to $2\times 10^{-5}$ or $3\times 10^{-5}$ achieved an ideal convergence equilibrium, allowing the classification head and upper transformer layers to adapt smoothly without destabilizing lower-layer syntactic representations. Conversely, an aggressive rate of $\eta = 5\times 10^{-5}$ introduced volatility; large gradient updates computed over small mini-batches caused loss oscillations, premature validation divergence, and an average 5.8\% reduction in validation Macro $F_1$.

Finally, evaluating batch size dynamics ($B = 8$ versus $B = 16$) demonstrated that smaller mini-batches offer a valuable implicit regularization benefit. In few-shot legal classification, mini-batches of size 8 introduce beneficial stochastic gradient noise that discourages optimizers from settling into sharp local minima. Across all evaluated model families, this setting consistently produced 2.5\% to 4.0\% higher validation Macro $F_1$ scores compared to batch size 16.
