\chapter{Methodology}
This chapter details the technical methodology used to build and evaluate the Coarse-to-Fine Semantic Conflict Detection System. It covers how the Philippine legal text is gathered and cleaned, how the two-stage Retrieve-then-Entail architecture is structured, and how the models are selected. It also outlines the evaluation metrics, the creation of the ground truth dataset, and the specific hardware constraints of the proponents, which are intended to mimic the standard computing capacity of an average Local Government Unit (LGU).


\section{Conceptual Framework}
This section maps how data flows through the proposed system. The architecture follows a basic Input-Process-Output (IPO) logic, broken into a two-step "Coarse-to-Fine" pipeline. By separating the task of searching for documents from the task of actually checking their logic, the system avoids the hardware bottlenecks that usually cause large language models to fail. The steps below outline how a raw document is processed into a final conflict alert.

    \subsection{Phase 1: Pre-Planning}
    This initial phase focuses on establishing the system's foundation by readying the offline database and finding the best logic model.

    \begin{description}
        \item[Corpus Processing.] The system first compiles a knowledge base by extracting over 10,000 national laws and local scanned ordinances. Because local municipal archives suffer from heavy optical character recognition (OCR) noise, the data undergoes rigorous cleaning and standardization. The finalized texts are then converted into mathematical vectors (embeddings) and stored offline in a pre-computed vector database.
        
        \item[Model Training \& Selection.] To ensure the system evaluates logic accurately, candidate Cross-Encoder models compete against a curated, expert-annotated Ground Truth dataset. The model that demonstrates the highest accuracy and F1-Score in detecting contradictions is selected as the permanent logic engine for the live system.
    \end{description}

    \subsection{Phase 2: Live System}
    The live system handles the actual consistency checking and is structured around an Input-Process-Output (IPO) pipeline.

    \begin{description}
        \item[System Input.] The live workflow begins when the user submits a new, ex-ante ordinance draft into the system. The system immediately cleans, standardizes, and vectorizes this submitted text so it can be compared against the pre-computed database.
        
        \item[Computational Process.] This part involves the two main stages: the information retrieval to retrieve relevant laws and the textual entailment to execute the conflict detection.
            \begin{description}
                \item[Stage 1: Information Retrieval. ] The system first acts as a broad search engine to rapidly reduce the massive database. It combines a basic lexical keyword search (BM25) from Team AIIR \cite{wu2025aiir} to filter out unrelated laws with a dense retrieval model (Bi-Encoder) that measures semantic vector distance inspired from Team JNLP \cite{coliee2025proceedings}. The scores are combined using weighted aggregation to extract only the top-k most relevant statutory candidates, which is the ensemble learning part derived from Team JNLP \cite{coliee2025proceedings}. 

                \item[Stage 2: Natural Language Inference] The pipeline then shifts to actual logical reasoning using the winning NLI model, implementing a framework specifically modeled after the Team KIS methodology \cite{kadowaki2025modernbert}. The system creates a unified input sequence that concatenates the proposed draft provisions with the retrieved existing laws into one continuous string. Following the "Binary Classification" strategy derived from Team KIS \cite{kadowaki2025modernbert}, the lightweight encoder bypasses text generation and performs a simultaneous binary classification. It evaluates the unified sequence by treating specific separation tokens as independent classification heads, outputting a binary probability score for each provision to judge multiple rules at the same time and mathematically determine if a logical conflict exists.
            \end{description}

        \item[System Output.] In the final stage, the system delivers a definitive verdict based on the model's calculated conflict probability. If no conflicts are detected, the system officially clears the draft. If a contradiction is flagged, the system outputs a detailed conflict mapping that specifies exactly which part of the text is conflicting. To ensure transparency, it utilizes Explainable AI (XAI) to project an attention heatmap, explicitly highlighting the exact words in the documents that triggered the semantic conflict.
    \end{description}


\section{Methodology}
This section outlines the comprehensive methodology governing the data collection, system engineering, and evaluation phases. It details the precise protocols used to build the pipeline from raw text acquisition to the final prototype demonstration.

    \subsection{Research Design}
    This research is fundamentally categorized as applied research designed to engineer a specialized software solution for civic governance. The experimental systems development approach is utilized to address the inherent complexities of the manual ordinance review bottleneck through automated detection. This explicit framing ensures methodological clarity regarding the integration of legal informatics and computational linguistic principles within a localized framework. By prioritizing the practical application of transformer-based architectures, the design bridges the gap between theoretical modeling and administrative deployment. The investigation serves as an empirical validation of the retrieve-then-entail pipeline's capability to operate within a specific regulatory environment.

    The experimental design involves isolating critical computational modules to measure retrieval latency and classification accuracy independently. Iterative prototyping allows for the systematic optimization of the information retrieval and natural language inference stages against local statutory data. This structured engineering logic ensures that the final artifact is optimized for the specific semantic nuances of municipal and national legislative texts. Applied research methodologies facilitate the direct translation of high-level NLP concepts into a functional tool for the Davao City Sangguniang Panlungsod. Consequently, the research outcomes establish a scalable benchmark for automating ex-ante consistency checks in evolving legal corpora.

    \subsection{Corpus Acquisition}
    The construction of the legal knowledge base requires the systematic compilation of text from disparate public repositories to ensure comprehensive statutory recall. These repositories host the national statutes and municipal enactments necessary for evaluating ex-ante legislative consistency. To preserve linguistic consistency and simplify vector representations, the system strictly acquires the English-language versions of all legal texts. This scope aligns with Philippine statutory construction rules where the English text is prioritized in the event of a conflict with vernacular translations. National statutes and local ordinances are gathered using distinct programmatic pipelines tailored to the specific document structures of each source.

        \subsubsection{Corpus Composition}
        The Lawphil Project serves as the primary repository for national statutory text due to its machine-readable HTML availability, uniform document structure, and extensive historical coverage~\cite{lawphil2000}. Automated scraping scripts navigate chronological and alphabetical indexes to extract Republic Acts, Batas Pambansa, Commonwealth Acts, Acts, Executive Orders, and Presidential Decrees. Executed through a programmatic web extraction pipeline developed by the proponents in early 2026, the national statutory extraction yielded 25,432 unique legal records spanning legislative enactments from 1900 to 2026. Supplemental official legal gazettes are utilized as secondary verification benchmarks to cross-reference enactment spans and historical amendments~\cite{officialgazette}. All retrieved national documents are converted into standardized JSON records with associated metadata, including enactment dates, formal titles, and structural provision hierarchies.

        The decision to extract national statutes exclusively from Lawphil addresses the severe archival fragmentation characteristic of public legal informatics. While the Official Gazette and congressional portals host statutory records, their web architectures exhibit shifting Document Object Model (DOM) hierarchies and non-searchable bitmap PDF scans for historical enactments. In contrast, Lawphil enforces a standardized HTML structure across all six constitutional eras, preserving clear typographic separation between statutory preambles and substantive provisions. Scraping solely from this centralized repository ensured absolute parsing uniformity across the 25,432 statutes, eliminating formatting discrepancies that would otherwise distort dense vector embeddings during Stage 1 retrieval. The resulting national repository provides an uninterrupted text foundation for semantic analysis and statutory preemption auditing.

        The Legislative Information Support System Program (LISSP) serves as the primary data source for Davao City municipal legislation~\cite{citygov2025lissp}. Following formal consultations with the Sangguniang Panlungsod (SP) legislative staff, the proponents obtained direct access to the municipal records. The resulting local archive comprises approximately 1,660 digitized ordinances enacted between 1946 and 2025. Unlike the digitally native HTML format of national statutes, the municipal archives primarily host scanned, image-based PDF files. These visual artifacts lack a searchable text layer, introducing character-level optical character recognition (OCR) noise that must be addressed prior to semantic processing.

        \subsubsection{Corpus Biases}
        An empirical examination of the raw statutory corpus reveals pronounced thematic imbalance across legislative domains. Over 40\% of the 25,432 national statutes comprise routine administrative measures, including the conversion of local schools, the renaming of public infrastructure, the delineation of territorial boundaries, and the granting of private telecommunications franchises. Conversely, substantive regulatory domains that frequently interact with municipal police powers—such as public health, land zoning, environmental protection, and local revenue administration—constitute less than 15\% of the raw national legislative volume. Unfiltered retrieval across this raw statutory distribution would introduce substantial domain bias, causing search algorithms to retrieve irrelevant administrative statutes instead of substantive regulatory provisions.

        The municipal archive exhibits severe temporal asymmetry and survivorship bias. For ordinances enacted prior to 2021, municipal preservation efforts predominantly prioritized the digitization of prominent ``Landmark Ordinances,'' leaving routine regulatory measures from earlier decades unindexed in physical paper storage~\cite{spdavao2026}. Consequently, the pre-2021 local subset represents an incomplete, highly curated selection of historically significant legislation rather than an exhaustive record of municipal governance. While post-2021 records acquired through the digital LISSP database are substantially more continuous, numerical gaps remain due to unreleased committee drafts and missing executive annexes. These archival inconsistencies create a temporal sampling gap that skews the municipal baseline toward recent administrative enactments.

        The physical condition of the scanned municipal archives introduces multimodal and linguistic noise. Historical ordinances scanned at low optical resolutions exhibit severe typography degradation, ink bleed, and scanning skew. Physical records also frequently contain non-textual artifacts such as official government stamps, councilor signatures, and handwritten marginalia that break standard sentence boundary tokenization. At the linguistic level, municipal documents occasionally introduce regional vocabulary and administrative Taglish within statutory preambles~\cite{dreisbach2021language}. These localized syntactic quirks differ sharply from the formal, sanitized legal English maintained in national statutory repositories.

        In natural legislative corpora, genuine statutory contradictions represent exceedingly rare edge cases. Democratic legislatures operate under a structural presumption of statutory harmony, actively avoiding direct conflicts with existing superior laws during drafting~\cite{fuller1964the}. Consequently, legitimate preemption events constitute less than 1\% of arbitrary pairs formed between municipal ordinances and national statutes. Naive, random sampling of text pairs from the compiled corpora would result in severe class collapse. A machine learning model trained on such an uncurated distribution would achieve over 99\% nominal classification accuracy by predicting ``Neutral'' across all instances while remaining completely incapable of identifying actionable legal conflicts.

    \subsection{Preprocessing and Filtering}
    The unstructured nature of the scraped archives necessitates an aggressive data cleaning, stratification, and normalization sequence. While national statutes are digitally native, the Davao City local ordinances act as the primary source of OCR-induced noise in the dataset. Because these local archives consist of scanned, image-based PDFs, the extraction process is prone to character misclassifications and erratic line breaks. The pipeline executes rule-based heuristics to identify and correct these artifacts specifically within the municipal ordinance subset. This targeted cleaning ensures that the subsequent semantic vectorization stage is not compromised by fragmented or unreadable text strings.

        \subsubsection{Domain Categorization}
        Raw legislative archives exhibit severe domain imbalance that hinders unconstrained semantic retrieval. In the compiled national corpus of 25,432 statutes, administrative enactments and private legislative grants constitute more than half of the historical volume. Inadvertently querying a proposed municipal regulatory ordinance against this unstratified collection leads to severe retrieval drift, as dense encoders frequently match generic procedural vocabulary across unrelated domains. Topic stratification acts as an automated triage mechanism, partitioning the statutory search space into substantive, semantically cohesive legal clusters. This modular organization prevents routine administrative laws from corrupting the candidate shortlist during ex-ante consistency auditing.

        The categorization pipeline executes an unsupervised discovery and consolidation workflow designed to operate efficiently on local computing hardware. First, the 25,432 statutory documents undergo text sanitization, stripping markup formatting and procedural metadata from the legislative text. The pipeline eliminates a custom lexicon of 49 domain-specific statutory stopwords, including terms like ``hereby,'' ``enacted,'' and ``republic,'' which carry high frequency across all legislative acts without providing domain-discriminating signal. Second, the cleaned texts are transformed into sublinear term frequency-inverse document frequency (TF-IDF) feature vectors, bounded to a maximum vocabulary of 25,000 unigrams and bigrams. To eliminate matrix sparsity and enable efficient local execution, the pipeline applies Truncated Singular Value Decomposition (SVD) to project the sparse representations into 64 latent semantic dimensions~\cite{deerwester1990indexing}, followed by $L_2$ unit-sphere normalization.

        Directly clustering legal documents into a small number of broad topics risks forcing distinct statutory templates into heterogeneous groupings. To prevent premature cluster conflation, the normalized 64-dimensional vectors are initially partitioned into $K = 28$ granular micro-clusters using MiniBatch $K$-Means clustering~\cite{sculley2010webscale}. This over-partitioned configuration allows repetitive statutory templates, such as local school conversions and telecommunications franchise grants, to aggregate into isolated, highly cohesive clusters. Following micro-clustering, the pipeline adapts the class-based TF-IDF ($c\text{-}TF\text{-}IDF$) formulation established by Grootendorst~\cite{grootendorst2022bertopic} to extract the most descriptive keyword representations for each group. By treating all text within a micro-cluster as a pooled composite document, $c\text{-}TF\text{-}IDF$ calculates term importance relative to the entire cluster collection rather than individual documents:

        \begin{equation}
            c\text{-}TF\text{-}IDF_{i, c} = \frac{|t_{i, c}|}{|c|} \times \log\left(1 + \frac{A}{\sum_{k} |t_{i, k}|}\right)
            \label{eq:c_tfidf}
        \end{equation}
        where $|t_{i, c}|$ represents the absolute frequency of word $i$ within cluster $c$, $|c|$ denotes the total word count of cluster $c$, and $A$ indicates the mean word count per cluster across the full collection.

        To translate raw mathematical clusters into legally meaningful categories, the extracted $c\text{-}TF\text{-}IDF$ keywords are scored against a curated Philippine statutory taxonomy. This taxonomy reflects the major devolved and reserved legislative competencies established in the Local Government Code of 1991~\cite{philgov1991ra7160}. Micro-clusters sharing common regulatory intents are consolidated under unified macro-domain labels. To eliminate statistical noise from hyper-specialized legislative edge cases, the pipeline enforces a strict minimum corpus threshold of $\ge 1.0\%$ ($N \ge 254$ statutes). Micro-clusters failing to meet this threshold are systematically reassigned to their closest semantic parent centroid, ensuring every resulting macro domain possesses sufficient density for reliable retrieval indexing:

        \begin{equation}
            \mathbf{C}_m = \frac{\sum_{i \in \mathcal{D}_m} \mathbf{z}_i}{\left\|\sum_{i \in \mathcal{D}_m} \mathbf{z}_i\right\|_2}, \quad P(m \mid \mathbf{z}_i) = \frac{\exp(\tau \cdot \cos(\mathbf{z}_i, \mathbf{C}_m))}{\sum_{j} \exp(\tau \cdot \cos(\mathbf{z}_i, \mathbf{C}_j))}
            \label{eq:macro_centroid}
        \end{equation}
        where $\mathbf{z}_i$ represents the normalized 64-dimensional SVD vector of document $i$, $\mathbf{C}_m$ denotes the normalized centroid of macro domain $m$, and $\tau = 6.0$ functions as the inverse temperature scaling parameter governing prediction confidence.

        \subsubsection{Preprocessing and Chunking}
        Following macro-domain stratification, document-level preprocessing sanitizes local ordinance texts and national statutory provisions.
        Custom regular expressions programmatically detect and strip repetitive legislative preamble blocks and signature rosters from municipal enactments.
        Unlike unstructured document collections, legislative enactments follow a rigid internal hierarchy consisting of chapters and codified sections.
        The proponents anchor statutory chunking at the Section level rather than imposing arbitrary fixed-token sliding windows~\cite{wu2025aiir}.
        In Philippine statutory drafting, the section functions as the fundamental self-contained normative envelope, defining an operative legal mandate together with its immediate provisos.

        Arbitrary token-window splitting routinely fractures statutory provisions, severing conditional caveats from their parent commands.
        When sub-clauses are extracted in isolation, they become syntactically headless and lose their governing institutional actors.
        To maintain legal coherence across sequence representations, the preprocessing pipeline implements Hierarchical Context Prepending prior to vector database indexing.
        Every extracted statutory segment is prepended with a structural metadata header containing the statute title, section number, and codified catchline:
        \begin{equation}
            \mathbf{x}_{\text{chunk}} = \left[ \text{Statute Title}, \text{ Section } S_i\text{: Catchline} \right] \mathbin{\Vert} \mathbf{t}_{\text{verbatim}}
            \label{eq:hierarchical_chunk}
        \end{equation}
        where $\mathbf{t}_{\text{verbatim}}$ denotes the exact text extracted from the Lawphil repository, and $\mathbin{\Vert}$ represents sequence concatenation.
        This structural prefix ensures that candidate Cross-Encoders in Stage~2 immediately identify the governing legislative jurisdiction and institutional actor.

        The legal necessity of hierarchical prepending is demonstrated by structural divisions within composite legislative codes.
        In Republic Act No.~7160, Section~447 establishes penalty caps for municipalities, whereas Section~458 establishes distinct penal authority for city councils.
        Without prepending the section catchline, downstream Cross-Encoders conflate distinct institutional tiers and misjudge municipal powers.
        Prepending the hierarchical metadata guarantees that the model evaluates the operative provision against its true administrative authority.
        Consequently, the vector representations preserve both the granular text of the clause and its authoritative statutory context.

        \subsubsection{Exception Handling}
        A central challenge in statutory conflict detection involves distinguishing genuine legislative preemption from authorized statutory exceptions.
        In national regulatory statutes, general prohibitions and conditional carve-outs frequently coexist within the same section through conditional provisos.
        Because section-level statutory chunks average between 200 and 500 tokens, the entire normative envelope fits comfortably within the 512-token context window of candidate Cross-Encoders.
        The joint cross-attention mechanism evaluates the general prohibition alongside its internal exceptions, preventing the system from flagging compliant local exceptions as false contradictions.
        This architectural alignment preserves the substantive legal relationship between regulatory baselines and authorized municipal carve-outs.

        Where general prohibitions and affirmative exceptions reside in separate statutory sections, the pipeline relies on dual-stage coordination.
        An ordinance clause drafting an authorized regulatory exception generates lexical and semantic cues matching both the prohibition and the exception provisions.
        The hybrid retriever in Stage~1 projects the query across dense and sparse indices, ensuring that both candidate sections enter the top-$k$ candidate shortlist.
        Stage~2 evaluates each candidate section independently, allowing the system to identify the authorizing statutory provision and confirm legal validity.
        This multi-candidate evaluation prevents premature conflict declarations on complex regulatory schemes containing distributed statutory exemptions.

        Statutory interpretation in Philippine jurisprudence requires enactments to be construed as a harmonious whole under the doctrine of \textit{in pari materia}.
        When a municipal draft exercises an authorized exemption, evaluating the prohibitory section in complete isolation produces a deceptive conflict alert.
        The hybrid retrieval mechanism captures this statutory interplay by retrieving both prohibitory rules and permissive exceptions into the top-$k$ candidate buffer.
        The Cross-Encoder assigns an Entailment classification when evaluated against the exemptive provision, confirming that the local measure operates under affirmative statutory authority.
        This dual-candidate assessment insulates the pipeline against false contradiction flags, ensuring that compliant local adaptations remain legally protected.

        \subsubsection{Class Balancing}
        In standard machine learning classification involving tabular data, severe class imbalance is routinely addressed through the Synthetic Minority Over-sampling Technique (SMOTE) \cite{chawla2002smote} or random feature-space interpolation. However, the proponents explicitly reject continuous vector oversampling algorithms for this legal textual pipeline. SMOTE operates by generating synthetic minority samples through linear interpolation between feature vectors ($x_{new} = x_i + \lambda(x_{zi} - x_i)$). In high-dimensional transformer embedding spaces representing discrete text, interpolating between continuous token embeddings yields nonsensical pseudo-embeddings that disrupt attention mechanisms and lack semantic or legal validity. Similarly, rule-based text augmentation techniques such as synonym replacement fail in the legal domain, as statutory terms of art carry rigid jurisprudential definitions; replacing modal auxiliaries like ``shall'' with permissive synonyms like ``may'' fundamentally alters legal obligations.

        To achieve a balanced, empirically sound Ground Truth dataset, the proponents employ a dual-pronged methodology combining historical extraction with human-in-the-loop adversarial text perturbation. First, researchers extract genuine, historically documented legislative clashes from municipal archival records, including mayoral veto messages, repealed local measures, and explicit statutory amendments \cite{italiani2026clash}. Second, adapting the adversarial annotation methodologies of Koreeda and Manning \cite{koreeda2021contract} and Nie et al. \cite{nie2020anli}, legal annotators deliberately inject contradictory constraints into genuine statutory provisions. Annotators systematically invert regulatory permissions, alter numerical zoning caps, and introduce conflicting penalties into ordinance spans. This expert-guided curation produces an artificially balanced distribution across the Entailment, Neutral, and Contradiction classes within the 350 curated Ground Truth pairs, preventing class collapse without compromising the syntactic authenticity of Philippine legal prose.

    \subsection{Ground Truth Process}
    Evaluating the deductive logic of candidate Cross-Encoder models in Stage 2 necessitates a highly specialized ground truth dataset. Unlike the coarse retrieval phase, the Natural Language Inference (NLI) pipeline requires deterministic, expert-validated examples to fine-tune and benchmark its binary classification accuracy. Because existing benchmarks fundamentally lack Philippine municipal context, a custom answer key must be curated specifically for the Davao City jurisdiction. This curated dataset provides the absolute objective baseline for identifying semantic preemption between local drafts and national statutes. Consequently, this ground truth process bridges the critical gap between raw computational vectorization and applied legal logic.

        \subsubsection{Span Pairing}
        To construct a statistically representative ground truth, the raw statutory corpus must first undergo strict topical categorization. The researchers deploy an existing machine learning classification model, engineered during a prerequisite academic elective, to assign the documents into specific legislative domains like zoning or taxation. Following this categorization, the system isolates specific national statutory provisions at the granular section level to serve as the fixed premise. However, to capture multi-hop reasoning and cross-sentence dependencies, the system abandons strict 1-to-1 sentence pairing. Instead, it utilizes Asymmetric Span-Level Pairing, where the corresponding hypothesis extracted from the local ordinance is maintained as a multi-sentence block \cite{yin2021docnli}. This asymmetric structure ($1 \text{ premise vs } N \text{ hypothesis sentences}$) ensures that contextual exceptions and referential pronouns within the local draft are evaluated holistically against the national rule \cite{koreeda2021contract}.

        To guarantee high ecological validity for the human evaluation, the hypothesis spans strictly emulate authentic Davao City legislative drafting conventions.
        The proponents analyzed enacted municipal legislation from the 2021--2025 Davao City ordinance repository, extracting standard operative formulas and administrative designations.
        Each drafted clause adopts authentic enacting syntax: ``\textit{SECTION X. [TITLE]. --- It shall be unlawful for any person, natural or juridical, within the territorial jurisdiction of Davao City, to...}''
        The hypotheses embed actual local enforcement bodies, pairing regulatory agencies like the City Transport and Traffic Management Office (CTTMO) and the City Health Office (CHO) with administrative offices like the City Environment and Natural Resources Office (CENRO) and the Business Bureau of Davao City.
        Specialized operational arms including the Anti-Vices Task Force (AVTF) and the Davao City Police Office (DCPO) are similarly incorporated to mirror genuine municipal delegations.

        The synthetic ordinance provisions are explicitly anchored to real administrative districts across Davao City.
        Draft measures specify geographic jurisdictions spanning urban sectors like Poblacion and Talomo, alongside suburban districts like Buhangin and Toril.
        Incorporating localized administrative entities like the City Disaster Risk Reduction and Management Office (CDRRMO) and the City Social Welfare and Development Office (CSWDO) guarantees institutional fidelity.
        This authentic legislative framing prevents evaluators from encountering artificial toy sentences that distort natural legal reasoning.
        Consequently, the 15 Sangguniang Panlungsod legal researchers evaluate realistic legislative proposals that accurately mirror draft measures introduced on First Reading.

        The corresponding hypothesis spans paired with the premise sentences are compiled using a hybrid approach of historical extraction and adversarial text perturbation. Initially, the researchers extract actual historical amendments and vetoed drafts from the municipal archive to capture natural legislative clashes \cite{italiani2026clash}. To ensure a balanced distribution of logical labels, annotators supplement the dataset by manually injecting negative constraints into existing spans, mirroring the perturbation strategies of Koreeda and Manning \cite{koreeda2021contract}. The inclusion of these human-engineered adversarial examples is statistically necessary to prevent the neural networks from relying on lazy lexical heuristics during inference \cite{nie2020anli}. These finalized, asymmetric premise-hypothesis pairs are then compiled into a structured evaluation instrument paired with strict coding guidelines for the human annotators.

        While the system utilizes asymmetric spans to capture intra-document context, it explicitly excludes cross-document multi-hop reasoning (i.e., identifying contradictions that only emerge when synthesizing two or more distinct national laws). Resolving multi-premise dependencies currently represents the bleeding edge of natural language inference. State-of-the-art frameworks addressing this require either computationally expensive entity graph retrieval \cite{lu2023multi} or the use of massive generative models for synthetic path generation \cite{shen2025hopweaver}. Implementing these N-vs-N architectures would immediately violate the strict consumer-grade hardware constraints established for Local Government Unit deployment. Consequently, the ground truth and subsequent inference pipeline are strictly bounded to single-premise evaluations.

        \subsubsection{Annotation Workflow}
        Manual classification of the sampled text pairs requires significant domain expertise to ensure jurisprudential accuracy. The Davao City Sangguniang Panlungsod currently operates with 24 elected councilors comprising of eight councilors from each of the city's three districts \cite{zuasola2025leadership}. After further clarification with the SP staff, the proponents discovered that the councilors are each supported by two dedicated legal researchers, creating a specialized talent pool of forty-eight professionals. Because interpreting local legislative preemption is their primary operational competency, the researchers will recruit fifteen of these active legal researchers through purposive availability sampling across the institutional pool rather than enforcing artificial district quotas. These annotators are provided with the stratified sample pairs alongside explicit classification guidelines detailing the exact conditions required for an Entailment, Contradiction, or Neutral logical state.

        Following the formal consensus protocol adapted from Ablazo~\cite{ablazo2019designing}, a logical classification is only accepted into the final Ground Truth if a minimum of two out of the three assigned experts agree. To mathematically validate this consensus across the groups, the system calculates Fleiss' Kappa to quantify the Inter-Rater Reliability (IRR). In each three-member sub-panel, the evaluator possessing the longest tenure in legislative drafting—measured by years of active legal research service in the Sangguniang Panlungsod—serves as the Lead Annotator. In instances where all three annotators provide conflicting labels—resulting in a complete absence of majority consensus—the item is not discarded. Instead, following the hierarchical adjudication protocols established for specialized domains by Gao et al.~\cite{gao2022hierarchical}, a designated Senior Legal Researcher from the SP intervenes as the formal Adjudicator to definitively establish the Gold Standard label.

        \subsubsection{Batched Annotation}
        To prevent annotation fatigue without compromising statistical reliability, this study directly adapts the batched distribution framework established by Ablazo \cite{ablazo2019designing}. In their baseline research for disaster-related text classification, Ablazo required an overlap of three independent evaluations per item to establish a valid majority consensus. To manage a dataset of 12,054 tweets, this required a total workload of over 36,000 individual annotations. By distributing this massive workload across a pool of 250 crowdsourced students, the required work per person was reduced to roughly 145 tweets. This established the precedent of using batched distribution to maintain a strict three-vote overlap without overwhelming the annotators.
        
        This study applies that exact mathematical framework to the specialized legal domain. Because cross-referencing multi-sentence ordinances requires significantly more cognitive load than reading short social media text, the dataset size is smaller, but the distribution logic remains identical. The exact allocation for the domain experts is mathematically derived as follows:
        
        $$\begin{aligned}
        N &= 350 \text{ premise-hypothesis pairs} \\
        k &= 3 \text{ independent votes per pair} \\
        P &= 15 \text{ legal annotators} \\[12pt]
        W &= N \times k \\
        W &= 350 \times 3 \\
        W &= 1,050 \text{ total annotations} \\[12pt]
        \text{Work per person} &= \frac{W}{P} \\
        \text{Work per person} &= \frac{1,050}{15} \\
        \text{Work per person} &= \mathbf{70 \text{ pairs per annotator}}
        \end{aligned}$$
        
        To execute this distribution practically, the dataset is partitioned into five equal blocks of 70 pairs each. The 15 researchers are divided into five distinct sub-panels of three experts, with each sub-panel independently evaluating a single block. This ensures every premise-hypothesis pair receives exactly three independent evaluations while keeping the individual workload highly manageable.

        To mitigate cognitive fatigue during manual annotation, the proponents implemented a multi-stage cognitive support protocol. Evaluating statutory pairs imposes substantial working memory demands, as evaluators must cross-reference multi-clause provisions against local ordinances. The evaluation interface distributes structured Google Sheets containing context-rich lead-in statutory text, preventing annotators from deciphering headless sub-clauses. Each evaluator receives a standardized one-page desktop reference sheet detailing the \textit{Magtajas} decision tree alongside statutory penalty ceilings. This procedural support minimizes decision latency and rater drift across the evaluation sessions, preserving high diagnostic consistency throughout the 70-pair evaluation blocks.

        \subsubsection{Inter-Rater Reliability}
        To mathematically validate the quality of the Ground Truth, the system evaluates annotator consensus using Fleiss' Kappa ($\kappa$). While raw percentage agreement indicates how often the panel selected the same logical label, it fails to account for instances where annotators might agree by pure random chance. Fleiss' Kappa isolates the actual analytical consensus by mathematically subtracting the probability of random guessing from the final score. 
        
        This specific statistical metric is explicitly required over Cohen's Kappa. Cohen's formula is strictly limited to evaluating exactly two raters, whereas the proposed batched distribution assigns exactly three experts per premise-hypothesis pair. The resulting reliability score is interpreted using the standard evaluation framework established by Landis and Koch \cite{landis1977measurement}. In their foundational statistical matrix, they explicitly delineate a $\kappa$ score between $0.61$ and $0.80$ as the strict mathematical threshold for "Substantial Agreement."

        Applying this specific baseline to natural language processing is empirically supported by Bowman et al. \cite{bowman2015snli} in the creation of the Stanford Natural Language Inference (SNLI) corpus. Evaluating semantic relationships is inherently subjective; in their benchmark study, Bowman et al. established an approximate performance ceiling for NLI tasks with an overall Fleiss' Kappa of $0.70$ (specifically scoring $0.77$ for Contradiction, $0.72$ for Entailment, and $0.60$ for Neutral). They demonstrated that achieving near-perfect agreement ($> 0.80$) in textual inference is highly improbable and usually indicative of overly simplistic test data. Because Philippine municipal legislation contains denser syntax than general English sentences, expecting an Inter-Rater Reliability score higher than the SNLI $0.70$ ceiling is statistically unrealistic. Therefore, the dataset targets a minimum $\kappa$ threshold of $0.61$. Surpassing this threshold officially classifies the expert consensus as "Substantial," mathematically proving that the rigid annotation guidelines successfully standardized the panel's legal reasoning.

    \subsection{Experimental Setup}
    The physical execution environment is deliberately restricted to consumer-grade hardware to mirror the standard computing capacity of an average Local Government Unit. All model training, vectorization, and inference tasks are processed on a local machine equipped with a standard central processing unit and adequate graphical memory. This specific constraint simulates the realistic technological boundaries of the Davao City legislative offices. By anchoring the experimental setup to accessible hardware, the research guarantees the pipeline's deployability without requiring expensive cloud computing infrastructure. The system must operate efficiently within these boundaries to prove its practical viability.

    Operating within these strict hardware limits mandates the explicit exclusion of massive Large Language Models (LLMs). Deploying generative architectures with billions of parameters would immediately exceed the available memory thresholds and incur unacceptable processing latency. Instead, the architecture strictly utilizes lightweight encoder-only models optimized for rapid sequence classification. This constraint forces the pipeline to rely on highly efficient vector math rather than computationally expensive autoregressive text generation. Consequently, the hardware limitations directly dictate the architectural shift towards the proposed Retrieve-then-Entail methodology.

    \subsection{Model Selection}
    Before the Natural Language Inference pipeline is deployed for live execution, the system must definitively identify the most accurate logic engine. The proponents execute an empirical selection phase to evaluate a pool of candidate Cross-Encoder architectures against the curated Ground Truth dataset. To satisfy the project's hardware constraints, the candidate pool is strictly limited to models that are relatively lightweight and memory-efficient. Despite their smaller size, these selected candidates possess a proven baseline performance in complex natural language reasoning tasks. By isolating these models against a standardized, expert-validated baseline, the process objectively determines which architecture best understands local legislative preemption.

    In order to ensure the empirical contest is statistically rigorous and reproducible, the 350 curated premise-hypothesis pairs are partitioned using a strict static split for the Train/Validation/Test of 70/15/15. This specific division yields 245 training pairs, 52 validation pairs, and 53 test pairs. Operating within this restricted sample threshold formally categorizes the evaluation as a few-shot fine-tuning scenario, a methodology proven highly viable for large language architectures \cite{gao2021making}. While $k$-fold cross-validation is traditionally favored, Vabalas et al. \cite{vabalas2019machine} mathematically demonstrate that static train/test splits are actually mandatory for datasets under 1,000 items to prevent optimistic bias and strictly control overfitting. Maintaining a 53-item test set also satisfies the Minimum Detectable Effect (MDE) thresholds established by Card et al. \cite{card2020with}, guaranteeing the test set possesses the statistical power needed to validate the architecture's reasoning improvements.

        The determination of the 350-pair benchmark volume is mathematically grounded in statistical power analysis for multi-class contingency evaluations~\cite{cohen1988statistical}. Under Cohen's power framework, detecting a medium effect size ($w = 0.30$) across a three-class classification matrix at significance level $\alpha = 0.05$ requires a minimum sample of $N = 108$ items for power $(1 - \beta) = 0.80$. Expanding the dataset to $N = 350$ pairs yields a statistical power exceeding $0.98$, guaranteeing adequate sample representation across each of the eight consolidated legal domains. These eight macro domains directly reflect the devolved basic services and regulatory police powers delineated under Section~17 and Section~458 of Republic Act No.~7160. Consequently, the 350 pairs provide sufficient statistical power for inter-rater consensus validation while establishing an ecologically valid cross-section of Philippine municipal governance.

        \subsubsection{Overfitting Control}
        Because fine-tuning deep bidirectional transformers on a specialized few-shot corpus risks memorizing the exact lexical phrasing of the training pairs, the proponents implement a rigorous regularization protocol. First, model optimization is executed using the AdamW algorithm with decoupled weight decay regularization ($\lambda = 0.01$), as formulated by Loshchilov and Hutter \cite{loshchilov2019decoupled}. This penalty continuously contracts parameter magnitudes toward zero, preventing individual network weights from growing disproportionately large. Second, dropout layers with an omission probability of $p = 0.1$ are enforced across the self-attention projections and the final dense classification head \cite{srivastava2014dropout}. By randomly deactivating a subset of neurons during forward passes, dropout forces the Cross-Encoder to learn distributed, resilient semantic representations rather than relying on brittle feature co-adaptations.

        Third, the training pipeline utilizes an automated early stopping mechanism governed by validation performance \cite{prechelt1998early}. The system computes the validation loss and validation Macro F1-Score at the conclusion of every training epoch. If the validation Macro F1 fails to achieve a measurable improvement over four consecutive evaluation checkpoints ($patience = 4$), the training run is immediately terminated. The optimization loop then restores the checkpoint that produced the lowest validation loss, effectively preventing the model from over-optimizing to idiosyncratic annotator syntax. Finally, the learning rate follows a linear warmup schedule over the initial 10\% of total training steps before transitioning to linear decay, ensuring stable gradient updates during the vulnerable initial adaptation phase.

    \subsection{Scope and Future Work}
    While the data preparation and regularization pipelines systematically mitigate sampling and class skew, certain structural constraints remain inherent to the dataset. First, restricting the corpus strictly to English-language texts excludes colloquial Cebuano phrasing and administrative Taglish frequently embedded in local committee deliberations. Second, the municipal dataset reflects a pronounced recency bias toward 2021--2025 enactments, as historical ordinances from earlier decades were digitized only when designated as landmark measures. Third, bounding the evaluation to single-premise asymmetric pairings ($1$-vs-$N$) prevents the automated detection of compound conflicts that emerge only when synthesizing two or more disparate national statutes. In accordance with the methodology's scope, these unavoidable residual limitations are explicitly acknowledged as empirical baselines, establishing the foundational research questions to be systematically addressed in the Future Work recommendations of Chapter 5.

    \subsection{Model Implementation}
    The live execution of the consistency checking system strictly follows a bifurcated architecture designed to balance rapid search speeds with deep logical accuracy.

    \begin{description}
        \item[Stage 1: Information Retrieval.] The live pipeline initiates when the user submits an ex-ante ordinance draft. The system first triggers the BM25 lexical algorithm to rapidly scan the static corpus. This sparse retrieval phase acts as a computational filter, immediately discarding laws that share zero keyword vocabulary with the drafted text. Simultaneously, the surviving documents are processed by the Bi-Encoder, which maps both the draft and the corpus into a dense vector space. The Bi-Encoder calculates the mathematical cosine distance between these vectors to capture deep semantic relationships that simple keyword matching misses. Once both the sparse and dense scores are calculated, the pipeline executes a weighted ensemble aggregation. Following the methodology established by Team JNLP, the system mathematically normalizes the distinct scoring outputs to ensure they operate on a compatible scale. The normalized scores are then merged using a pre-defined weighting parameter to balance exact keyword matches with broader semantic relevance. This merged calculation generates a strictly ordered shortlist containing only the top-k most relevant statutory provisions. By restricting the output, the system effectively isolates the specific legal texts required for the subsequent deep logic review without overloading the hardware.

        \item[Stage 2: Natural Language Inference.] Upon receiving the top-$k$ shortlist from Stage 1, the pipeline transitions to rigorous logical evaluation using the Natural Language Inference (NLI) module. The system programmatically constructs a unified input sequence for each retrieved candidate provision. It concatenates the retrieved statutory text (functioning as the premise) and the drafted ordinance (functioning as the hypothesis) into a single string. To guide the attention mechanism of the selected logic engine, the pipeline injects strict structural markers, specifically placing a $[CLS]$ token at the sequence start and a $[SEP]$ token between the two legal texts. This formatting ensures the model mathematically recognizes the boundary between the existing law and the proposed rule. The formatted sequence is then fed into the pre-selected Cross-Encoder model for simultaneous processing. The model leverages disentangled attention mechanisms to evaluate the semantic dependencies between every token in the premise against every token in the hypothesis. It executes a binary classification over the entire sequence, calculating the precise logical relationship between the paired texts. The final layer of the architecture outputs calibrated softmax probabilities that explicitly label the relationship as an Entailment, Contradiction, or Neutral state. If the contradiction probability exceeds the designated safety threshold, the system triggers the Explainable AI (XAI) module to flag the provision for user review.
    \end{description}

Section-level structural chunking prevents the dilution of singular penal constraints, ensuring that high-dimensional embeddings reflect specific operative rules rather than composite statutory averages~\cite{reimers2019sentencebert}. Expanding the candidate shortlist to $k = 50$ provides a generous diagnostic buffer, allowing the fine Cross-Encoder to evaluate borderline candidate provisions that fall outside the top ten results. Consequently, the Stage~1 retrieval mechanism guarantees high recall while preserving computational efficiency on consumer-grade local hardware.

        The structural decoupling of Stage~1 retrieval from Stage~2 inference is computationally mandatory on local workstation hardware. Ingesting full-length statutory enactments directly into a Cross-Encoder incurs an $O((L_{\text{ord}} + L_{\text{stat}})^2)$ quadratic computational complexity, triggering immediate memory exhaustion when processing extensive legislative codes. Full-text ingestion also causes severe attention dilution, burying isolated penal prohibitions within thousands of irrelevant procedural tokens. The Stage~1 hybrid retriever executes a rapid $25,432 \rightarrow 50 \rightarrow 1$ coarse-to-fine triage, filtering over 99.8\% of non-relevant national enactments within milliseconds. This asymmetric decoupling enables the deep Cross-Encoder to allocate all available self-attention capacity exclusively to high-probability statutory candidates.

    \subsection{Evaluation Metrics}
    Evaluating the performance of the Coarse-to-Fine pipeline requires distinct mathematical metrics across its two sequential operational stages. The coarse retrieval phase in Stage~1 prioritizes candidate recall over logical classification, whereas the inference phase in Stage~2 requires fine diagnostic precision to eliminate false conflict alerts.

        \subsubsection{Stage 1 Metrics}
        Evaluating the candidate ranking performance of Stage~1 requires specialized ranking metrics rather than standard classification accuracy~\cite{manning2008introduction}. Because the operational goal of the coarse retriever is candidate isolation rather than final decision-making, standard accuracy formulas fail to reflect retrieval quality. If the governing national statute is omitted from the top-$k$ shortlist, the downstream Cross-Encoder cannot detect the legal preemption regardless of its inferential capacity. Consequently, the information retrieval stage is evaluated primarily through Recall at rank $k$ ($\text{Recall@}k$) across predefined thresholds of $k \in \{10, 30, 50\}$. This metric quantifies the proportion of test queries for which the authoritative national provision is successfully retrieved within the designated candidate shortlist:

        \begin{equation}
            \text{Recall@}k = \frac{1}{|Q|} \sum_{q=1}^{|Q|} \mathbf{1}\left(\text{rank}(d_q^*) \le k\right)
            \label{eq:recall_at_k}
        \end{equation}
        where $|Q|$ denotes the total number of evaluated test queries, $d_q^*$ represents the ground-truth national statutory provision paired with query $q$, and $\mathbf{1}(\cdot)$ is an indicator function returning one if the ground-truth document ranks within the top $k$ candidates.

        To measure positional ranking efficiency within the candidate shortlist, the proponents evaluate Mean Reciprocal Rank ($\text{MRR@}k$)~\cite{manning2008introduction, robertson2009probabilistic}. While $\text{Recall@}k$ treats all positions within the top-$k$ shortlist equally, $\text{MRR@}k$ penalizes systems that place the governing statutory provision further down the ranking hierarchy:

        \begin{equation}
            \text{MRR@}k = \frac{1}{|Q|} \sum_{q=1}^{|Q|} \frac{1}{\text{rank}(d_q^*)} \cdot \mathbf{1}\left(\text{rank}(d_q^*) \le k\right)
            \label{eq:mrr_at_k}
        \end{equation}
        In this mathematical formulation, a ground-truth statutory provision retrieved at rank one yields a reciprocal score of 1.0, whereas a provision retrieved at rank ten yields 0.10. The 350 curated premise-hypothesis pairs serve as the empirical query benchmark for evaluating Stage~1. By executing all 350 municipal draft hypotheses as search queries against the 25,432-statute database, the proponents measure the exact frequency with which candidate retrieval models recover the paired statutory premise. Establishing an empirical baseline across $\text{Recall@}10$, $\text{Recall@}30$, and $\text{Recall@}50$ confirms whether the coarse retriever supplies a reliable candidate pool for subsequent natural language inference.

        \subsubsection{Stage 2 Metrics}
        The predictive performance of the classification models is quantified using standard mathematical evaluation metrics. Precision is calculated as the ratio of true positive contradiction flags to the total number of flags generated by the system. Recall is computed as the ratio of true positive contradiction flags to the total actual contradictions defined in the Ground Truth. These specific measurements isolate the model's ability to minimize false alarms while successfully catching genuine legal conflicts. High precision ensures users are not overwhelmed with incorrect alerts, while high recall guarantees critical preemptions are not ignored.

        To establish a single comparative baseline for the candidate models, the system computes the harmonic mean of precision and recall. This metric, defined mathematically as the F1-Score, provides a balanced assessment of the model's overall diagnostic accuracy. The calculation heavily penalizes extreme disparities between precision and recall, ensuring the selected model does not favor one metric at the expense of the other. The Cross-Encoder achieving the highest F1-Score on the annotated pairs is permanently integrated into the final pipeline. These rigorous mathematical evaluations validate the system's empirical reliability before deployment.

    \subsection{Prototype Development}
    The validated algorithmic pipeline is ultimately deployed as a lightweight, single-page web application to facilitate end-user interaction. The graphical user interface is deliberately engineered with minimal complexity, visually mirroring the straightforward architecture of standard online file conversion utilities. Users initiate the diagnostic process through a drag-and-drop upload zone that accepts the ex-ante ordinance drafts in standard document formats. Upon submission, the interface activates a real-time loading state to indicate that the dual-stage retrieval and inference pipeline is actively processing the text against the static corpus. This minimalist design eliminates extraneous navigational elements, ensuring the legislative staff can execute the semantic conflict check without requiring specialized technical training.

    Upon completion of the pipeline execution, the system dynamically updates the interface to display a multi-tiered results dashboard. To ensure transparency in the Information Retrieval stage, the interface provides a dedicated section listing the top-$k$ statutory provisions extracted during Stage 1. This "source transparency" module allows users to verify which national laws were prioritized as semantically relevant prior to the deep inference classification. If a conflict is flagged, the dashboard generates a granular error report explicitly juxtaposing the specific sentence in the submitted draft against the exact conflicting provision. The report includes a numerical confidence score derived from the logic engine, mathematically justifying why a particular section was identified as a contradiction.

    The diagnostic prototype operates strictly as a Human-in-the-Loop decision-support system during First Reading committee evaluations. Rather than substituting for human legal reasoning, the tool flags potential statutory collisions to accelerate pre-enactment legal scrutiny. The Explainable AI module generates token-level self-attention heatmaps, highlighting the exact phrase spans that triggered the contradiction probability score. Sangguniang Panlungsod legal researchers inspect these visual heatmaps to assess whether the flagged text represents an unconstitutional preemption or an authorized local variance. This collaborative workflow enables legislative staff to proactively amend vulnerable draft clauses before formal plenary enactment, preventing invalid municipal legislation.
