This appendix presents the operational layouts, component views, and explainable decision-support interfaces of the single-page prototype web application engineered for the Davao City Sangguniang Panlungsod.

\section{System Interface Architecture}
\label{sec:app_ui_overview}

The prototype interface operates as an offline single-page application built on a local web server (Streamlit runtime, Host~A edge desktop). The interface decouples procedural document ingestion from neural inference through four primary user-facing views:

\begin{enumerate}
    \item \textbf{Draft Ingestion Drawer:} Enables legal officers to drag and drop raw Philippine Folio PDF files ($8.5 \times 13.0$~inches) or paste digital legislative text. An integrated regex state machine automatically isolates substantive operative provisions while stripping procedural recitals, titles, and administrative boilerplates.
    \item \textbf{Dual-Stream Retrieval Inspector:} Displays candidate statutory provisions partitioned into vertical preemption candidates (superior national laws from Lawphil) and horizontal coherence candidates (existing Davao City ordinances).
    \item \textbf{Side-by-Side Explainable AI (XAI) Card:} Renders the draft ordinance clause alongside the authentic verbatim statutory provision. Token-level self-attention weights highlight conflicting modal verbs (e.g., \textit{shall} versus \textit{prohibited}) using colored bounding boxes, accompanied by doctrinal preemption summaries without editorial modification of the positive statutory text.
    \item \textbf{Calibrated Decision Gauge:} Displays an immediate conflict probability meter calibrated at the empirical cost-sensitive threshold $\tau^* = 0.45$. Draft sections exceeding the threshold trigger a prominent warning card recommending committee referral.
\end{enumerate}
