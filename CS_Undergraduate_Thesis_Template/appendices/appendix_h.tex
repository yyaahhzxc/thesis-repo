\chapter{Prototype Dashboard Architecture}
\label{app:prototype_dashboard}

This appendix presents the user interface and interaction architecture of the functional decision-support prototype developed for ex-ante ordinance conflict detection. Designed for legislative researchers and legal staff at the Sangguniang Panlungsod of Davao City, the prototype translates the two-stage machine learning pipeline (Stage~1 hybrid retrieval and Stage~2 Cross-Encoder natural language inference) into an accessible, single-page web dashboard. The prototype is implemented with a lightweight Python Flask backend delivering asynchronous Server-Sent Events (SSE) and a responsive client-side interface styled in official Ateneo and city legislative maroon (\texttt{\#7F2723}) branding.

\section{Overview and Operational Workflow}
\label{sec:app_h_overview}

The web interface operationalizes the ex-ante conflict detection workflow through four primary views: the default draft ingestion workspace, real-time scanning overlay, substantive conflict triage summary, and the top-50 statutory candidate transparency table. The landing interface features a prominent drag-and-drop upload zone that accepts digital-born drafts in searchable PDF, scanned physical pages, and plaintext formats (\texttt{.pdf}, \texttt{.txt}, \texttt{.json}). Upon document ingestion, client-side JavaScript initiates an asynchronous multipart POST request to the \texttt{/api/audit-document-stream} backend endpoint, establishing an active EventSource stream to report per-section chunking, candidate scanning, and cross-attention tensor evaluation progress in real time.

\section{Dual-Accordion Comparative Provision Inspection}
\label{sec:app_h_accordions}

To ensure complete legal transparency and avoid black-box decision making, each detected preemption risk is presented within an expandable comparative accordion. Figure~\ref{fig:prototype_conflict_accordion} illustrates the expanded inspection view comparing authentic statutory text against the proposed draft ordinance.

\begin{figure}[!htbp]
    \centering

    }
    \caption[Expanded Conflict Accordion and Provision Comparison]{Expanded Conflict Accordion with Verbatim Statutory Comparison}
    \label{fig:prototype_conflict_accordion}
\end{figure}

Within the expanded accordion body, operative legal text is organized into two side-by-side dropdown cards: the controlling superior national statute (or existing Davao City ordinance in horizontal audits) and the proposed draft clause. In strict accordance with the Zero Editorial Pollution Protocol, the text rendered in each card is 100\% verbatim authentic text directly extracted from official repositories (e.g., Section~458(a)(1)(iii) of Republic Act No.~7160 governing municipal penalty ceilings). Each comparative card functions as an independent collapsible dropdown, allowing legislative researchers to minimize individual boxes during review of long, multi-paragraph enactments.

Each candidate entry presents the retrieval rank, statutory citation, unabridged title, hybrid Stage~1 similarity score, and a direct hyperlink routing to the verified source on Lawphil or the official Davao City legislative portal.
